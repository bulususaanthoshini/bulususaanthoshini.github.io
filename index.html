🎯 What Is WWE-AllStars-Recomp?

WWE All Stars was released for the Xbox 360, and until now the only way to play it was on that original console or through complicated emulation setups. WWE-AllStars-Recomp changes that. It is an unofficial Windows version of the game, produced through a technique called static recompilation using the ReXGlue toolchain.

In plain language: the code that used to run on the Xbox 360 hardware has been translated ahead of time into code your Windows PC understands. Instead of translating every instruction live at high speed — which is what an emulator does — the translation work is already finished before you ever press Play. The result is a smoother, lighter experience that behaves more like a normal Windows game than like an emulator window.

Rendering is handled through Vulkan, the modern graphics interface supported by essentially every current AMD, NVIDIA, and Intel graphics chip. That means the game can take advantage of your graphics card properly, with clean image output and responsive performance.

This project does not include the game's original data. You are expected to bring your own disc image — a copy of the game disc you already own. The recompiled program is the engine; your disc image is the content it reads.

🎮 Controls and Display

Plug in a controller before you start the program and Windows will recognise it automatically. Most players find a gamepad far more comfortable for a wrestling title, since the analog stick gives finer movement and the shoulder buttons map naturally to strikes and grapples.

On the display side, the safest starting point is your monitor's native resolution with fullscreen enabled. If you notice uneven motion, try switching between fullscreen and windowed mode, and make sure your graphics driver is current — Vulkan performance depends heavily on a recent driver. Laptop owners should also set the power plan to High Performance while plugged in, as battery-saving modes can throttle the graphics chip and cause stutter.

🛠️ Troubleshooting

  • The program closes immediately. Update your graphics driver first. Vulkan support is the most common culprit, and a driver update fixes it more often than anything else.
  • You are asked for a disc image. That prompt is expected. Point the program at your own copy of the game — it cannot start without it.
  • The image looks blurry or stretched. Match the resolution to your monitor's native setting and toggle fullscreen mode off and on again.
  • Frames drop during entrances. Entrances are the heaviest part of the game. Lower the resolution one step and performance usually smooths out.
  • Your controller is not detected. Unplug it, close the program, reconnect the controller, and launch again. Windows sometimes assigns a controller slot before the game looks for one.
  • Antivirus flags the download. Community-made programs are frequently flagged because they are not signed by a large publisher. Add an exception, or check the releases page for the newest build.
  • Something still is not right. Check the issues area of the project on GitHub. Someone has very likely hit the same problem and posted a fix.

❓ Frequently Asked Questions

Is this an emulator?
No. Emulators translate instructions while the game runs. This project translates the game's code ahead of time through static recompilation with ReXGlue, so what you run is a Windows program built specifically for the task.

Do I need an Xbox 360?
No console is required. You do need your own disc image of the game, which you are expected to create from a copy you own.

Does the game come bundled?
No. The download is the recompiled engine only. The game's content stays on your own disc image.

Will it run on a laptop?
Yes, on most recent laptops with Vulkan-capable graphics. Keep the laptop plugged in and use the High Performance power plan for the best results.

Do I need to install anything else?
Keep your Windows updates and graphics drivers current and you should be ready to go.

How often is it updated?
The releases page shows the newest build at the top. If you hit a bug, check there first for a fix.

Is it free?
Yes. The project is a fan-made, unofficial recompilation effort and does not charge for the software.
